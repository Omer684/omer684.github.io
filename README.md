# Muhammad Omer | Portfolio

React + Vite portfolio. All text lives in `src/data.js`; edit it there.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to GitHub Pages
Upload every file to the root of the `Omer684.github.io` repository, then open Settings > Pages and choose **GitHub Actions**. The workflow in `.github/workflows/deploy.yml` builds and publishes on every push to `main`.

## Before publishing
- Confirm every GitHub link in `src/data.js` opens a public repository.
- Check that each metric (R² 0.94, 15–20× speed-up, $13.59M) matches your repository READMEs and resume.
- Test the contact form once (Formspree: `mrppbwro`) and confirm it reaches your inbox.
- `public/Muhammad_Omer_Resume.pdf` is your current resume. Replace it with the same filename when you update it.
- The hero image (`public/selected-hero.png`) is an edited composite, not an unedited photo.
